# FRAP

FRAP studies Rubik puzzles, from abstract polytopes to N-by-N-by-N cubes,
the 3-by-3-by-3 cube, solution methods, and gameplay, with group theory
connecting the topics.

The starting point is Giovanni Luca Marchetti's
[*Rubik's Abstract Polytopes*](https://arxiv.org/abs/2502.13518).
Mathematical notes are being prepared in
[Forest](https://github.com/utensil/forest).

This repository is an initial skeleton. It has no Lean implementation yet.
