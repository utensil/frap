# FRAP

- Ground mathematical notes in literature and Lean work in the notes.
- Add Lean code only when it offers a distinct contribution beyond the
  reference projects.
- Use cleanroom methodology: derive designs from mathematical principles,
  literature, observed behavior, and technical specifications. Do not copy
  reference implementations or their core ideas. Attribute inspiration.
- Keep private planning and coordination out of public artifacts.
- Keep changes small and verify the work they affect.
